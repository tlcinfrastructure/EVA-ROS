# Put this snapshot on GitHub

1. Extract the ZIP. The EVA-ROS folder is the repository root.
2. Review README, STATUS, credits and the files before publishing.
3. Create a repository on your own GitHub account.
4. Push the extracted source tree using Git, GitHub Desktop or GitHub's file-upload interface. Do not upload only the ZIP if you want browsable source files.

This package contains no .git directory, remote URL, token, machine diagnostic log or real local baseline. No repository has been created and nothing has been pushed automatically.

Keep config/local-machine.json, evidence, backups, environment files and generated local logs out of commits; .gitignore covers these paths. Verify staged files before pushing. Keep the Phase 3 pending status in the initial commit/release description.
